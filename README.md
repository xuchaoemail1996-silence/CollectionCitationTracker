# Collection Citation Tracker · Zotero 分类引用标记

**按分类独立记录文献引用状态，让每篇论文都有自己的引用清单。**

Collection Citation Tracker 是一个面向论文写作和研究项目管理的 Zotero 插件。它在文献列表中增加“引用状态”列，支持通过右键菜单将文献标记为已引用、未引用或清除标记，并支持批量操作。

插件的核心特点是：**引用状态属于当前分类，同一篇文献在不同分类中的标记互不影响。** 适合为每篇论文、文献综述或研究项目分别建立 Zotero 分类的使用方式。

## 为什么需要按分类标记？

同一篇文献经常会被放入多个论文或研究项目的分类中。但“这篇文献是否已经引用”取决于具体的写作项目。

例如，同一篇关于人工智能与劳动力市场的文献，可以有以下状态：

| 所在分类 | 当前项目中的使用情况 | 引用状态 |
| --- | --- | --- |
| 论文 A：人工智能与工资 | 已写入正文并引用 | ✓ 已引用 |
| 论文 B：人工智能与性别就业 | 已核对，尚未引用 | ○ 未引用 |
| 文献综述：技术进步与劳动市场 | 尚未核对是否使用 | — 未标记 |

在“论文 A”中修改状态，不会改变“论文 B”或“文献综述”中的记录。你可以在多个项目中复用同一文献条目，同时分别管理各项目的引用进度。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 按分类独立记录 | 同一篇文献在不同分类中可以具有不同的引用状态 |
| 引用状态列 | 在 Zotero 主文献列表中直接显示状态，无需逐条打开文献 |
| 三种状态 | 区分“已引用”“未引用”和“未标记” |
| 右键快捷操作 | 在文献右键菜单中设置或清除当前分类的标记 |
| 批量标记 | 同时选中多条文献，一次完成统一标记 |
| 状态排序 | 点击“引用状态”列标题，按状态排列文献 |
| 本地保存 | 标记保存后，关闭并重新打开 Zotero 仍可读取 |
| 保留文献原始信息 | 不修改文献字段、标签、笔记或附件 |

### 三种状态的含义

| 显示内容 | 含义 | 建议使用时机 |
| --- | --- | --- |
| ✓ 已引用 | 已确认在当前分类对应的论文或项目中引用 | 完成正文引用后 |
| ○ 未引用 | 已核对，明确当前尚未引用 | 检查后确认尚未使用时 |
| — 未标记 | 尚未设置状态，或已清除原有标记 | 尚未核对或需要重新核对时 |

**“未标记”不等于“未引用”。** 保留这一区别，可以避免将尚未核对的文献误认为已经检查过。

## 安装方法

1. 打开本项目的 [Releases 页面](https://github.com/xuchaoemail1996-silence/CollectionCitationTracker/releases)，进入对应版本，下载 `CollectionCitationTracker-1.0.1.xpi`。
2. 在 Zotero 中打开 **工具 → 插件（Tools → Plugins）**。
3. 将下载的 `.xpi` 文件拖入插件管理窗口，按提示完成安装。也可以通过插件管理窗口中的“从文件安装”选项选择该文件。
4. 返回 Zotero 主界面查看“引用状态”列；如果安装过程中提示重启，请按提示重启 Zotero。

**安装插件需要下载 `.xpi` 文件。** GitHub 自动提供的 `Source code (zip)` 和 `Source code (tar.gz)` 是源码下载入口，不是直接安装包。

安装方式也可参考 [Zotero 官方插件说明](https://www.zotero.org/support/plugins)。

## 使用方法

### 1. 选择具体分类

在 Zotero 左侧选中一个分类，例如：

- 人工智能与工资论文
- 性别就业研究
- 技术进步文献综述

建议为每篇论文或每个项目建立独立分类，方便明确“已引用”对应的是哪份稿件。

### 2. 显示“引用状态”列

在主文献列表中找到 **引用状态** 列。

如果该列没有显示，右键点击列表表头，在列选择菜单中勾选 **引用状态**。它可以与标题、作者、年份等列表列共同显示。

### 3. 标记单篇文献

选中文献主条目，右键打开菜单，找到：

**当前分类：引用状态**

在子菜单中选择：

- **✓ 标记为已引用**
- **○ 标记为未引用**
- **× 清除此分类的标记**

操作完成后，列表中的引用状态会更新。

### 4. 批量标记多篇文献

先选中需要处理的多条文献，再通过相同的右键菜单进行操作。

- **Windows / Linux**：按住 Ctrl 点击，可选择多条不连续的文献。
- **macOS**：按住 Command 点击，可选择多条不连续的文献。
- **连续选择**：使用 Shift 选择一段连续文献。

例如，完成一个章节的引用核对后，可以一次将对应文献全部标记为“已引用”。

### 5. 清除标记

选择 **× 清除此分类的标记** 后，所选文献在当前分类中的状态会恢复为 **— 未标记**。

清除操作只影响**所选文献在当前分类中的记录**，不会清除它们在其他分类中的标记。

### 6. 按状态查看文献

点击 **引用状态** 列标题，可以按状态排列文献，方便集中查看已引用、未引用和未标记的条目。

切换到另一个分类后，列表显示的是该分类自己的记录。

## 推荐的论文写作流程

1. **建立项目分类**：为每篇论文、综述或研究项目创建一个分类。
2. **收集候选文献**：把可能使用的文献加入分类，先保留为“未标记”。
3. **边写边记录**：在正文中使用并完成引用后，将文献标记为“已引用”。
4. **核对候选文献**：确认尚未使用的文献可以标记为“未引用”，尚未检查的继续保留“未标记”。
5. **提交前检查**：按引用状态整理列表，并与最终稿件核对；如果正文引用发生变化，及时调整标记。

这个流程既适用于独立论文，也适用于同时推进多个项目的写作过程。

## 使用范围与规则

### 分类之间互不影响

不同分类分别保存记录。父分类和子分类也各自独立，不会自动继承或合并引用状态。

如果同一篇文献同时出现在父分类和子分类中，需要分别设置它在这两个分类中的状态。

### 在具体分类中操作

本插件的标记入口是**具体分类中的文献主条目**。

以下位置或条目不提供相同的标记入口：

- “我的文库”等文库根节点
- 保存的搜索
- 单独的 PDF 附件或其他附件条目
- 单独的笔记条目

如果选中的是 PDF 附件，请改为选中它所属的文献主条目。

### 由用户确认引用状态

插件记录用户设置的状态，不读取 Word、LaTeX 或其他稿件文件，也不会自动判断正文中是否引用了某篇文献。

如果删除或新增了正文引用，需要手动更新 Zotero 中的对应标记。“已引用”表示用户已经确认的状态，最终提交前仍应与稿件核对。

## 数据保存与备份

引用标记保存在当前 Zotero 用户配置文件（profile）的本地偏好设置中，按文库、分类和文献分别记录。

- **重启 Zotero**：已经保存的标记仍可读取。
- **跨设备同步**：标记不会随 Zotero 账号自动同步到另一台电脑。
- **文献原始信息**：标记不会写入文献字段、标签或笔记。
- **卸载插件**：当前版本不会主动删除已经保存的引用记录；在同一配置文件中重新安装本插件后，可继续读取原有记录。
- **删除并重建分类**：即使新分类名称相同，它也具有新的内部标识，旧分类的标记不会自动迁移。

如果这些记录对写作很重要，请备份 **Zotero 用户配置文件**。仅备份文献数据库或附件目录，不应视为已经备份了本插件的引用标记。

引用标记功能不向外部服务器上传文献内容或标记记录。

## 常见问题

### 找不到“当前分类：引用状态”右键菜单怎么办？

先在左侧选中一个具体分类，再选中其中的文献主条目。文库根节点、保存的搜索、单独的附件或笔记不是本插件的标记入口。

### 标记后，列表没有立即更新怎么办？

切换到其他分类，再切回原分类。如果仍然异常，可尝试重启 Zotero，并在 Issues 中提供复现步骤及错误信息。

### 为什么同一篇文献换一个分类后变成“未标记”？

这是按分类独立记录的正常行为。该文献在当前分类中尚未设置状态，不影响它在其他分类中已经保存的记录。

### 清除标记会删除文献吗？

不会。清除操作只删除所选文献在当前分类中的引用状态记录，不会删除文献、附件、标签或笔记。

### 能否同时管理多篇论文？

可以。为不同论文建立独立分类，并在各分类中分别维护引用状态即可。

如果两篇论文共用同一分类，插件无法进一步区分它们的引用记录，因此建议为两篇论文分别建立分类。

### 如何更新插件？

在 Releases 页面查看新版说明，下载新的 `.xpi` 文件，并通过 Zotero 插件管理窗口安装。

保持同一 Zotero 用户配置文件和同一插件 ID 的版本升级，可以继续读取原有标记。更新前建议备份用户配置文件。

## English

**Collection Citation Tracker** is a Zotero plugin with a Chinese interface for tracking citation status independently in each collection.

It adds a citation-status column and an item context menu. Users can mark regular items as **cited**, **uncited**, or **unmarked**, with support for multiple selected items.

The same item can have different statuses in different collections. Parent and child collections also keep separate records.

Statuses are assigned manually and stored in the local Zotero profile. They do not sync across devices, and the plugin does not inspect manuscripts or modify bibliographic metadata, tags, notes, or attachments.

The author has used the plugin in Zotero **9.0.6** during actual literature management and manuscript writing. The manifest targets Zotero **9.0.x**.

Download the `.xpi` installation file from [Releases](https://github.com/xuchaoemail1996-silence/CollectionCitationTracker/releases).
