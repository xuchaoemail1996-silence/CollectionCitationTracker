# v1.0.1 · 分类引用标记

Collection Citation Tracker 是一个按 Zotero 分类独立管理引用状态的轻量插件。你可以把分类作为一篇论文或一个研究项目的文献清单，并分别记录每条文献是否已经引用。

同一篇文献在“论文 A”中可标为已引用，在“论文 B”中可保持未标记，互不影响。

## 主要功能

- 为当前分类中的文献标记 **已引用 / 未引用 / 未标记**。
- 文献列表新增 **引用状态** 列，支持按状态排序。
- 通过右键菜单操作，支持多选批量标记。
- 本地保存记录，重启 Zotero 后保留。
- 不修改文献字段、标签或笔记。

## 本版调整

- 补全安装清单中的 `update_url` 和 `homepage_url` 字段。
- 将引用状态列配置为在主文献列表的默认视图中显示。
- 正式发布构建会配置 GitHub 项目主页、更新清单和 XPI 下载地址。

## 安装

下载本页附件 **`CollectionCitationTracker-1.0.1.xpi`**，然后在 Zotero 的 **工具 → 插件 → 齿轮 → 从文件安装插件…** 中选择该文件。按提示完成安装或重启。

请使用 XPI 安装，源码 ZIP 用于查看和开发。

## 适用范围

清单目标版本为 **Zotero 9.0.x**，原始开发目标是 Zotero 9.0.6。此工作环境尚未完成真实 Zotero 客户端的安装和界面验证。

状态需要手动标记，插件不会读取论文并自动识别引用；标记保存在本地，不会随 Zotero 账号跨设备同步。首次使用时，请在具体分类中选中文献主条目进行标记。
